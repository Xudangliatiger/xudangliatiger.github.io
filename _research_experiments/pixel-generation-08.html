01 / 误差起点

L0 决定模式，fine-level temperature 只是在噪声与平均之间移动

v0.17.7 的固定 checkpoint sweep 显示，no-CFG 下 temperature ≈ 0.70–0.75 是相对稳定的视觉区间。温度更高会增加颜色与局部变化，但很快转成 block noise 与 salt-and-pepper；温度更低则压制采样，同时让结构更保守、更模糊。

按层调节温度后，结论更清楚：保持 L0 不变，只升高 L1/L2，增加的主要是非结构化高频噪声；把 L1/L2 降到 0.50 / 0.25 能去掉部分颗粒，却不能把模糊边界变成一致的细边缘。

当前判断

采样温度可以调节当前分布的随机性，却不能替代缺失的 child-pixel coupling，也不能让 fine level 主动改写错误的 coarse mode。

02 / GT forcing

给对第一层以后，层级明显稳定；但误差仍会逐层积累

GT-L0 诊断把第一层 sampled RGB 替换成真实 coarse target，再让后续层按 temperature=0.75 自由生成。语义、颜色与布局立刻更稳定，说明正常 free run 的主要不确定性确实从 L0 开始。

进一步把五层模型的前四层都强制为 GT 时，最终 L16 能够在正确 prefix 上生成接近真实布局的结果。这证明最后一层并非完全不会读取好的 hierarchy；正常推理失败更像是历史逐层漂移，而不是 final head 单独失效。

  1. 01

    GT L0 显著改善全局模式

    第一层对物体身份、主色和布局的影响远大于 fine-level temperature。

  2. 02

    GT history + sampled L0 仍会放大局部偏差

    即使历史位置正确，一次错误的 L0 value 仍可能在 L1/L2 扩大。

  3. 03

    正确前缀下 final level 可以工作

    这把问题定位到 sampled-history robustness 与 coarse calibration，而不是简单删除 fine levels。

03 / 层数与成本

五层增加了像素位置，却没有在同一步数下增加清晰结构

同一 40k checkpoint 诊断：三层约 25.01s，五层约 42.36s，即本次设置下慢 1.69×；新增 L8/L16 没有产生清晰的语义收益。

这个 1.69× 不是可推广的系统性能结论，只适用于同一脚本、同一硬件和该次采样设置。它支持的窄结论是：在当前 HPA 中，增加两个完全采样的层级显著提高依赖路径与推理成本，而同一步数下没有看到相应视觉收益。

04 / 高频残差

真实细节存在；生成 hierarchy 在深层系统性低估它

GT multiresolution pyramid 使用与模型相同的 target construction：patch-wise area downsample、8-bit rounding，再 nearest upsample 进行展示。相邻层残差包含物体轮廓、毛发、文字、建筑边缘和细纹理，因此“后期 target 本身没有信息”可以排除。

05 / 目标改造

Focal loss 能找到困难像素，但没有证明它就是主瓶颈

teacher-forced DMoL NLL map 与边缘/高频区域明显对齐。v0.17.8.1 因此尝试按 per-channel probability 进行 focal weighting：

\[p_i=e^{-\mathrm{NLL}_i/3},\quad w_i=\mathrm{stopgrad}(1-p_i)^2,\quad \mathcal L=\frac{\sum_i w_i\mathrm{NLL}_i}{\sum_i w_i+\epsilon}.\]

focal reweighting 后的视觉质量总体相近。它确认 loss 能定位难点，但没有受控证据表明最终生成质量改善。

blur-history、noisy-history 和“热 L0、冷 finer levels”也都对应合理假设，但当前记录不足以把它们写成成功方法。下一篇转向更强的结构变化：把随机性集中在一次 patch-level AR 选择，细层 decoder 只负责条件 refinement。
