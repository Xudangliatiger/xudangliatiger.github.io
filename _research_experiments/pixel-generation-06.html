01 / 顺序设计

并行哪些像素，等价于规定哪些像素不能互相条件化

完全 raster-order 的 256×256 Pixel AR 需要 65,536 个顺序步骤，无法直接作为高效生成器。v0.18.x 去掉 patchify，改为一次预测一个空间 group：group 内像素同时输出 DMoL 参数，group 之间保持自回归。

版本一个 token 表示顺序轮次同组缺失依赖
v0.18.1一条完整图像对角线约 511同一对角线内像素
v0.18.2一列 256 个像素256同一列内的纵向像素
v0.18.316×16 raster L0 → 32 列 L1分层已有代码，未见完整训练结果
核心取舍

group 越大，顺序轮次越少；但同组像素的条件独立假设越强，生成方向越容易成为图像纹理的一部分。

02 / 训练结果

Diagonal 与 Column 都没有把并行像素组织成稳定语义

v0.18.1 在约 58k step 的本地样本仍以噪声化结构为主；v0.18.2 训练到约 117k step 后，能够形成更大尺度的颜色区域，但可见列方向传播、竖向条带与周期重复。对 v0.18.2 的 temperature sweep 也没有把这些模式转化成稳定的 ImageNet 语义。

v0.18.1 · step 58k。对角线级并行降低了串行深度，但样本仍以方向性噪声和弱结构为主。

v0.18.2 · step 117k。列 token 把一整列同时采样，结果中出现与左到右生成方向一致的条带与传播痕迹。

03 / 周期诊断

把“看起来有条纹”变成可比较的 phase variation

为了避免只依赖挑选图片，我们对每个数据集的 100 张样本计算不同空间周期 P ∈ {2,4,8,16,32} 下的 gradient 与 Laplacian phase profile。对每个周期，使用各 phase 均值的范围相对于全局均值：

\[A_P=\frac{\max_k m_{P,k}-\min_k m_{P,k}}{\bar m_P}.\]

在 period 32 的横向梯度上，column 模型的 A₃₂ ≈ 0.302，diagonal 模型约为 0.056。这个差异与列方向条带的视觉现象一致：column grouping 把更强的横向 phase 偏置写进了样本分布。

04 / 结论边界

这是分布级偏置，不是逐图可见的 watermark

  1. 01

    已证实：空间顺序会改变伪影方向

    Diagonal 与 column 的样本及 phase profile 呈现不同的方向性偏置。

  2. 02

    已证实：更少步骤不等于更好生成

    把一列像素并行预测虽然只需 256 轮，但同列无条件依赖造成新的结构缺口。

  3. 03

    不能声称：每一张图都含可检测水印

    现有分析支持 cohort-level distribution effect；它没有恢复逐图精确 RGB 模板。

  4. 04

    未验证：v0.18.3 修复了问题

    raster L0 + column L1 已有模型、配置与脚本，但没有本地可见的完整训练产物。

05 / 下一步

需要层级上下文，也需要更细的组间通信

纯 diagonal / column 模型把效率问题变成了空间依赖问题。下一阶段不再让一种全图顺序独自承担语义与细节，而是回到多分辨率层级：粗层负责全局模式，细层逐步增加像素密度，并显式研究 sampled value 与 hidden belief 如何跨层传递。
