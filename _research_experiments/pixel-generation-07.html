01 / 共享层级

把多个 RGB 分辨率写进同一条 token 序列

CascadeAR 为每个尺度使用独立模块，跨层接口很多，也很难判断改进来自网络容量还是信息路径。v0.17.7 的 Hierarchical Pixel AR（HPA）改用一个共享主干：每个 macro patch 在 1×1、2×2 和 4×4 三个尺度各形成一个 token group，所有 groups 按层级顺序拼接进同一条 causal sequence。

\[S=[S_{L1};S_{L2};S_{L4}],\qquad H=\mathrm{Transformer}_{\theta}(S).\]

不同尺度的值维度不同，因此输入 RGB encoder 与 DMoL prediction head 仍然是 level-specific；Transformer、causal attention 与大部分参数共享。RoPE 在每一层重复使用 patch grid，learned level embedding 用于区分分辨率。

验证目标

如果一个共享因果空间能够同时表示 coarse belief 与 fine refinement，就可以减少跨层模块差异，并让所有细层直接读取更早的全局上下文。

03 / 生成结果

共享模型能逐层细化，但细层没有可靠修正 coarse branch

v0.17.7：L1、L2、L4 与 deterministic decoder0。后续层提高名义分辨率并略微锐化，但没有稳定修复第一层已经选错的物体结构或边界。

正面结果是明确的：L0 能产生类别相关的颜色与布局，共享 Transformer 也能把这些状态传给更细层；模型不是“层级拼接后完全学不动”。但三层意味着每个 patch grid 的序列位置被重复三次，当前训练记录显示成本接近单层的三倍。

同时，细层 DMoL 在一个 token 内并行预测多个 RGB values。它们能读取相同的 coarse context，却缺少充分的 within-patch coordination；因此更热的采样往往增加盐胡椒噪声，更冷的采样又走向平滑平均。

04 / 失败模式

结构共享没有自动解决三类误差

  1. 01

    Coarse branch 选择错误

    第一层一旦采样到错误颜色、布局或局部模式，后续层更常继承而不是推翻。

  2. 02

    Parallel DMoL 缺少组内协调

    一个 fine token 同时采样多个像素；边缘位置不确定时，各像素容易分别选择不同模式。

  3. 03

    增加层数同时增加曝光偏差

    训练看到 GT history，推理看到 sampled history。每加入一层，都增加一次分布漂移的机会。

Patch-MDN 的早期结果没有给出清晰修复，但训练步数与 DMoL baseline 不匹配，因此这里不能公开声称“DMoL 普遍优于 Patch-MDN”。更准确的表述是：在现有预算和 checkpoint 下，改变输出分布族不足以解决层级误差。

05 / 研究决定

下一轮先定位误差起点，再讨论是否继续加层

HPA 已经通过架构可行性验证，后续不再以“能否共享 Transformer”为主问题。我们转而做 controlled diagnostics：固定 checkpoint 扫 temperature / CFG，强制 GT L0 或 GT history，比较三层与五层的同一步数结果，并用 Laplacian residual 判断细层究竟增加了多少新信息。
