01 / 替换接口

把 codebook token 换成下采样 RGB

上一篇的一步 decoder 仍然依赖预训练 tokenizer。v0.16.8 做了最直接的替换：Semantic AR 不再预测 code id，而是预测一个低分辨率 RGB scaffold r_t；一步 decoder 同时读取 sampled RGB 与隐藏状态 h_t，渲染完整 patch。

目标

保持 Pixel input → Pixel state → Pixel output，不借助 VQ codebook；让粗 RGB 承担模式选择，让 hidden state 补足剩余信息。

这个设计仍然保留两个路径：sampled value path 把已经落地的 coarse RGB 送到下一阶段；hidden-state path 通过 condition 提供尚未采样的分布信息。它比纯回归更接近多峰生成，也比 tokenizer 路线更“像素原生”。

02 / 观察结果

布局能够形成，但细节没有随分辨率一起恢复

v0.16.8.5c free-run 结果：低分辨率 RGB 能传递大致颜色、布局和物体身份，但边界与纹理经常呈现模糊或周期性块状结构。

这不是“完全无法生成”的失败。相反，样本证明粗 RGB 是一个有效的布局提示；问题在于它不足以唯一确定高分辨率 patch。两种解码策略对应两类不同症状：

路径模型行为可见症状
Mean / regression对多个可能细节取条件平均纹理被洗平、边缘变软
Sampled coarse RGB把一次低分辨率采样当作后续硬条件采样偏差累积为 grid / patch artifact

03 / 问题定位

低分辨率 RGB 是统计摘要，不是可还原的模式索引

一个 1×1、2×2 或 4×4 的 RGB 值只描述局部平均颜色与粗轮廓。大量不同纹理、边缘位置与物体细节都可以下采样到同一个值，因此一般有：

\[H(X_{\mathrm{high}}\mid R_{\mathrm{low}}) \gg 0.\]

这与 v0.16.7 中更接近 codebook/token 的表示不同。一个学习到的 mode token 可以专门编码高分辨率 patch 身份，而 low-res RGB 并没有被训练成可逆索引。于是“v0.16.7 有正面结果”不能被解释成“raw low-res RGB 也是充分 latent”。

CODEX_LOG 中 v0.16.8.x 与随后 v0.17.2.x 都出现了相似的周期性块状噪声。跨分支重复出现使“coarse sample 分布漂移”成为更可信的解释，但目前仍不能排除 decoder 容量、训练/推理不一致和 patch 独立采样共同造成的影响。

04 / 当前结论

应该传递 belief，而不是只传递一次 coarse sample

  1. 01

    已证实：coarse RGB 能传递布局

    物体类别、主色和大尺度空间结构在 free-run 样本中可见。

  2. 02

    已证实：直接 mean decode 会丢细节

    当一个低分辨率值对应多个 patch 时，deterministic renderer 倾向条件平均。

  3. 03

    当前解释：硬传 sampled RGB 会累积误差

    一旦 coarse sample 离开训练分布，下游把它当成事实继续细化，难以主动修正。

  4. 04

    架构要求：value 与 belief 分开

    sampled value 记录已经作出的选择；hidden state 应保留可选模式的分布摘要，供下一尺度读取。

05 / CascadeAR 复核

拆成多个尺度以后，歧义不会自动消失

v0.17.4–17.5 随后把一次 1 → 16 跳跃改成 [1,2,4] CascadeAR，用实际训练检验 sampled value、hidden condition 与 residual target。结果比单尺度实验更具体，但仍没有给出“coarse RGB 足够”的正面证据。

v0.17.x 分支汇总：不同 history、condition 与 residual 路径改变了失败形态，但没有稳定消除块状结构和细节不足。

版本实际证据当前判断
v0.17.4 hard-fuse[1,2,4] 主基线有约 130k checkpoint多尺度接口能够训练，但不是充分性证明
v0.17.4.3 GT-history + low-res CA约 9.5 小时后因样本噪声大、趋势不佳而停止仅增加 cross-attention 没有触及核心问题
v0.17.4.3b GT hard-fuse120k temperature sweep 仍有 block artifacts训练历史更干净也没有消除 free-run 症状
v0.17.5 Laplacian residualpatch-local upsample 与 residual 路径通过 debug长训练和 streaming sampling 未完成，效果未知

因此，更准确的结论不是“严格证明低分辨率 RGB 永远不充分”，而是：在这些接口、容量和训练设置下，粗 RGB 没有携带足够的可恢复细节；简单增加层级或条件通道也没有稳定解决 sampled-history drift。

06 / 下一步

不要让一个 coarse RGB token 一步解释完整 patch

最自然的修正是把 1 → 16 的硬跳跃拆成多个分辨率层级，并在每一层重新建模自己的分布。下一阶段因此分成两条并行问题：一条研究 pixel 的生成顺序，比较 diagonal、column 等 grouped AR；另一条构建 CascadeAR，系统比较 sampled value、hidden condition 与 cross-attention 应怎样进入下一尺度。
