01 / Ordering diagnosis

Spatial generation order leaves a directional fingerprint across a sample cohort

Rather than flattening an image into an arbitrary sequence, v0.18.x compares diagonal and column groups. v0.18.1 leaves actual diagonal samples at about 58k steps; v0.18.2 leaves column samples around 117k / 110k. Both produce image structure, but their periodic patterns differ.

v0.18.1 · diagonal groups · step 58k. Global structure forms, while group boundaries can still surface in local texture.

v0.18.2 · column groups · step 117k. Changing the spatial organization changes where errors accumulate.

For period-32 horizontal-gradient statistics, phase variation is about 30.2% in the column cohort and 5.6% in the diagonal cohort. This supports the claim that grouping direction changes aggregate bias. It does not show that every column sample has the same 32-pixel watermark, nor does comparison of unmatched checkpoints rank one order above the other.

Diagnosis

Spatial factorization is not merely an implementation detail. Which positions communicate first and which positions run in parallel changes the direction and period of visible errors.

02 / Prototype

v0.19.1 implements a minimal checkerboard A/B path, but provides no result

v0.19.1 divides a 256×256 image into 256 macro patches of 16×16 pixels and partitions them into checkerboard A/B phases. The 128 patches inside one phase share each pixel step, while every patch retains strict raster-order Pixel AR; Phase B may read the generated Phase A.

03 / Multilevel Phase Schedule

The same image gains resolution from L0 to L4: global AR at L0, then batched A/B phases

The interactive figure exposes the five spatial levels of the full design. L0-L4 render the same image at 16², 32², 64², 128², and 256², corresponding to 1², 2², 4², 8², and 16² RGB pixels inside each macro patch. L0 retains a conventional raster-order scan over 256 coarse RGB tokens. Only L1-L4 split the 256 patches into A/B groups and advance 128 patches at a time. This visualizes the proposed full Phase-Parallel HPA schedule; it does not claim that v0.19.1 already implements five-level training.

One image, refined in place: each phase overwrites only its checkerboard half

This second view removes the duplicate A/B canvases and follows one persistent image. After L0 finishes, L1A changes only A while B remains at L0 resolution; L1B then replaces the remaining B pixels. The completed L1 image becomes the base for L2, and the same process continues through L4.

{% include research/refinement-v0191.html lang='en' %}

One shared HPA trunk, one lightweight Pixel AR head

The top-level design follows v0.17.7: every level and phase reuses one causal HPA Transformer instead of creating a new network, but its token granularity changes by stage. L0 is conventional next-token AR: one coarse RGB token enters and the model predicts the next. At each L1-L4 phase transition, 128 carrier tokens enter the shared HPA as one masked parallel group and produce 128 patch conditions h_i. Conditioned by AdaLN, the lightweight Pixel AR head remains autoregressive inside each patch, while all 128 patch-local next-token loops run in parallel. For readability, the animation groups A/B positions into two contiguous blocks after L0; an implementation can express the same order through indices and the causal mask without physically permuting tokens.

Training. Expand the nine stage groups in one graph, supervise the HPA transitions with the stage mask, and teacher-force each patch-local RGB sequence. Inference. Run one highlighted stage at a time, sample the tiny Pixel AR head, re-embed its phase RGB, and pass that carrier into the same HPA for the next stage.

Resource implication, still only a design estimate. The logical sequence remains 256 + 8×128 = 1,280 HPA tokens. Rolling pre-eviction would keep about 128 carrier tokens resident and peak near 256; post-eviction would keep about 256 and peak near 384, versus up to 1,280 for full history. Treating B as a compressed carrier of earlier A remains a hypothesis that needs a full-history control. A block mask alone also does not reduce dense-kernel FLOPs.

Implementation boundary

v0.19.1 implements two-stage checkerboarding and patch batching, but remains a two-level [1,16] model. Phase communication uses a separate bidirectional context layer, and Pixel AR receives one 64-dimensional prefix rather than the shared Phase AR, rolling KV, or AdaLN proposed below.

04 / Full hypothesis

Replace fully serial Patch AR with cross-level, cross-phase, and within-patch dependencies

v0.17.7 establishes that one shared causal Transformer can train and sample across RGB levels. The proposal only replaces each level's total patch order with a two-phase partial order.

01

Coarse AR

The 256 coarse RGB values at L0 remain globally autoregressive and carry semantics and layout.

Retain the HPA trunk
02

Phase AR

L1-L4 generate A before B; one large shared Transformer carries state across levels and phases.

Two-stage partial order
03

Patch RGB AR

The 128 patches in a phase advance the current pixel together, while each patch preserves raster causality.

Strict local AR

The full five-level proposal needs 2(4+16+64+256)=680 synchronized local Pixel AR rounds. Adding 256 L0 rounds and eight phase transitions gives a dependency path of roughly 944. This describes the computational graph, not a measured speedup.

The condition interface would also grow from a single 64-dimensional prefix to layer-wise modulation: parent RGB, pixel position, level, and phase jointly generate AdaLN parameters. Shared-Transformer KV states would roll across phases so memory and retained history become an explicit, measurable trade-off.

05 / Unknowns

Five questions must be isolated before the design is credible

  1. 01

    Is within-phase conditional independence too strong?

    Checkerboarding prevents same-phase patches from sharing horizontal or vertical edges, but does not guarantee consistent color, texture, or long-range structure.

  2. 02

    Does A→B communication help?

    A no-A→B control is required to separate the checkerboard partition from the value of phase communication.

  3. 03

    Where does the teacher-forcing gap begin?

    Sampled parent, sampled Phase A, and sampled pixel history must be substituted separately rather than collapsed into one free run.

  4. 04

    Does AdaLN use its condition?

    Correct, shuffled, and zero conditions should create interpretable NLL differences; training loss alone cannot establish this.

  5. 05

    When should rolling KV be evicted?

    Pre-eviction, post-eviction, and full history must be compared on quality, memory, and phase latency.

Current verdict

We have evidence that spatial ordering creates directional bias and that a phase-parallel path can be implemented. We do not yet have evidence that it improves quality, speed, or patch-boundary continuity.
